# Litgram Messenger

Собственный мессенджер для iOS. Код написан с нуля на SwiftUI, не основан на
исходниках Litgram и не использует чужие форки.

В приложении есть чаты, контакты, профиль и галерея из 151 оригинального
NFT-подарка Litgram (названия, цены в звёздах и миниатюры). Модели и цены
взяты из официального снимка каталога подарков; сам код мессенджера — свой.

- Bundle ID: `org.litgram.messenger`
- Сборка: GitHub Actions, `.github/workflows/build-ipa.yml`, unsigned IPA
- Курс ₽/⭐ настраивается в профиле (по умолчанию 1 ⭐ = 2 ₽)
